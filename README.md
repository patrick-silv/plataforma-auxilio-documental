# plataforma-auxilio-documental
Projeto académico independente de extensão do curso de Engenharia de Software da UNIGRAN Europa. A Plataforma de Auxílio Documental (PAD) disponibiliza gratuitamente guias sobre NIF, NISS, saúde e residência em Portugal, com checklists e acesso a fontes oficiais. Site: https://auxiliodocumental.biz
